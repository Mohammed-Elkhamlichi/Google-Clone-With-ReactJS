## 🚀 Getting Started

### Prerequisites

Install the following tools before running the application:

- [Node.js](https://nodejs.org/)
- npm
- [Git](https://git-scm.com/)

### 1. Clone the repository

```bash
git clone https://github.com/Mohammed-Elkhamlichi/Google-Clone-With-ReactJS.git
```

### 2. Navigate to the project directory

```bash
cd Google-Clone-With-ReactJS
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm start
```

### 5. Open the application

Visit [http://localhost:3000](http://localhost:3000) in your browser.

*These commands assume the project uses Create React App and defines the standard `start` script. Check `package.json` if the commands differ.*
